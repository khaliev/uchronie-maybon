# T05 — Design System (CSS Moderne)

## Objectif
Créer l'interface visuelle "Moderne & Classique" sans aucun framework (Pur CSS).

## Contraintes
- Palette : Bordeaux (#681D2A), Champagne (#C5A46D), Ivoire, Noyer.
- Performance : CSS global < 60Ko.
- Accessibilité : Contrastes contrastés (WCAG AA).

## Étapes
1. Créer `tokens.css` (variables de couleurs, typos, espacements).
2. Créer la grille de mise en page (Flexbox/Grid).
3. Designer les composants (Boutons, Cartes, Menu).

## Definition of Done
- [ ] Styleguide.html fonctionnel montrant tous les éléments graphiques.
