# T06 — Développement du moteur de Build

## Objectif
Créer le script Node.js qui assemble les pages statiques.

## Étapes
1. Développer `scripts/build.mjs`.
2. Gérer l'injection des `partials` (Header/Footer) dans les pages.
3. Gérer la conversion Markdown -> HTML pour le corps des pages.

## Definition of Done
- [ ] La commande `node scripts/build.mjs` génère un dossier `dist/` complet.
