# T02 — Récupération et optimisation des Assets

## Objectif
Récupérer les images, logos et icônes originaux et les préparer pour une performance maximale.

## Entrées
- docs/source-urls.md

## Étapes
1. Télécharger les images originales dans `src/assets/images/originals/`.
2. Créer les versions optimisées dans `optimized/` (Format WebP et AVIF).
3. Générer des tailles adaptées pour le responsive (Mobile/Desktop).
4. Créer `docs/inventaire-assets.csv` avec les textes alternatifs (alt) trouvés sur Wix.

## Interdits
- Ne pas utiliser de noms de fichiers génériques (img1.jpg). Utiliser le SEO-naming.

## Definition of Done
- [ ] Assets optimisés et classés.
- [ ] Inventaire CSV complété.
